## Главный проект — ZAG Atlas

### [База знаний компании с AI-помощником](https://github.com/Denis-Zag/ZAG-Atlas)

Мой выпускной проект: веб-приложение для менеджера сервисной компании. Сотрудник задаёт вопрос по внутренним документам и получает ответ с цитатами и ссылками на источники. Если сведений не хватает, система показывает, что нужно уточнить, и сохраняет причину ручной проверки.

**Что реализовал:** загрузку PDF, DOCX, TXT и MD с предпросмотром, распознавание текста со сканов, поиск по базе знаний, персональные учётные записи и роли, историю вопросов и аудит действий.

[Смотреть демо](https://disk.yandex.ru/i/yeqlG7qqGTrTVA) · [Код и инструкция запуска](https://github.com/Denis-Zag/ZAG-Atlas)

![ZAG Atlas: вопрос сотрудника, ответ и цитата из документа](https://raw.githubusercontent.com/Denis-Zag/ZAG-Atlas/main/docs/screenshots/08_answer_current.png)

**Подтверждения:** в репозитории сохранены результаты 99 офлайн-тестов, живых проверок, импорта файлов и сохранения данных при запуске в Docker. Основные сценарии интерфейса проверены вручную. Это локальная версия; полный серверный запуск с доменом и HTTPS пока не проверен.

**Стек:** Python, FastAPI, SQLite, Qdrant, LLM API, Docker Compose.

# Привет! Я — Денис 👋

**Python-разработчик • Telegram-боты • AI-ассистенты • Автоматизация**

Работаю в сфере Python-разработки, AI и автоматизации.

Создаю Telegram- и VK-ботов, REST API и интеграции с внешними сервисами. Помогаю автоматизировать сбор заявок, работу с документами и подготовку отчётов.

## Что разрабатываю

- **Боты и AI-ассистенты** — диалог с памятью, ответы по документам, итоги командных обсуждений.
- **Сервисы для работы с заявками и данными** — приём обращений, классификация, учёт клиентов, сделок и задач.
- **Интеграции и автоматизация** — обмен данными через API, отчёты в Google Sheets, сборка и публикация Docker-образов через GitHub Actions.

## Избранные проекты

### [Freelance Mini CRM](https://github.com/Denis-Zag/Freelance-Mini-CRM)

Учёт клиентов, сделок и задач в одном приложении. Можно отслеживать сроки и статусы, а отчёты создавать в Google Sheets через пользовательскую OAuth2-авторизацию.

**Реализовано:** REST API, локальный интерфейс, база данных и выгрузка отчётов. В README — скриншоты работы приложения.

**Стек:** Python, FastAPI, SQLite, Tkinter, Docker Compose, Google Drive API и Google Sheets API.

### [AI-ассистент по PDF и DOCX](https://github.com/Denis-Zag/telegram-docling-study-assistant)

Telegram-бот превращает загруженные документы в персональную базу знаний: находит подходящие фрагменты и формирует ответы с указанием использованных файлов и страниц.

**Реализовано:** обработка документов, поиск по смыслу, разделение данных пользователей и удаление загруженных материалов по команде.

**Стек:** Python, aiogram, Docling, Haystack, Pinecone, LLM API.

### [AI-ассистент командного чата](https://github.com/Denis-Zag/telegram-team-ai-assistant)

Telegram-бот сохраняет обсуждение команды, отвечает по переписке и документам, а после остановки записи формирует итоги: решения, открытые вопросы и следующие действия.

**Реализовано:** запись сообщений, обработка PDF/DOCX, поиск по контексту и разделение данных групп и сессий.

**Стек:** Python, aiogram, SQLite, Pinecone, Docling, Haystack, LLM API.

### [Auto Service AI Triage](https://github.com/Denis-Zag/auto-service-ai-triage)

Сервис для первичного разбора обращений в автосервис: определяет тему сообщения, готовит черновик ответа и отмечает случаи для передачи оператору.

**Реализовано:** API классификации, SQL-хранилище, резервный сценарий при недоступности модели, автоматические тесты и проверка Docker-сборки через GitHub Actions. В README — скриншоты и ссылка на демо-видео.

**Стек:** Python, FastAPI, SQL, LLM API, Docker, GitHub Actions.
